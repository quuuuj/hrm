# 数智人事系统（一）：Flowable审批流 + RAG知识库 + 智能问答

**数智人事**是一套前后端分离的人力资源管理系统。本期围绕标题中的三个核心能力展开——**Flowable 审批流**、**RAG 知识库**与**智能问答**，分别对应流程驱动、知识沉淀与 AI 答疑三条链路：

- **Flowable 审批流**：请假单据经 Flowable 8.0 引擎走 HR、经理两级审批，审批通过触发考勤写入与调休扣减，驳回则将单据状态重置；加班与薪资由纯计算模块直接核算，不接入流程引擎。
- **RAG 知识库**：制度文档经 MinIO 存储、ETL 解析切块、Embedding 向量化后落入 PostgreSQL pgvector，检索采用向量与关键词 RRF 混合召回并做邻窗扩展。
- **智能问答**：员工提问先经意图识别与改写，命中知识库后拼接员工档案上下文送大模型生成回答，最终以流式输出逐字推送至前端。

在此之上，系统覆盖传统人事业务闭环——组织架构、员工档案、RBAC 权限、考勤打卡、加班与假期、薪资与五险一金。

系统包含两条核心业务链路：**请假审批**（通过 Flowable 引擎驱动，加班由纯计算类直接核算）与**知识库问答**。

### 选型清单

| 组件 | 选型 | 说明 |
| :--- | :--- | :--- |
| 后端框架 | Spring Boot 3.4.4 + Java 17 | 核心基础框架，Flowable 8 原生支持 Boot 3 |
| ORM | MyBatis-Plus 3.5.10 | 单表 CRUD 无 XML，复杂查询采用注解 SQL |
| 工作流 | Flowable 8.0 | 原生适配 Spring Boot 3，负责请假审批流程驱动 |
| 鉴权 | JWT 双 Token + HttpOnly Cookie | 规避 XSS 风险，支持无感续期 |
| 权限 | Spring Security @PreAuthorize | 权限点持久化，登录时装入 JWT Claim，避免逐次查库 |
| 业务库 | MySQL 8.1（两库分离） | 业务主库与 Flowable 流程库独立，物理隔离 |
| 向量库 | PostgreSQL 16 + pgvector | 基于 pgvector 扩展实现向量近邻检索，无需独立向量库 |
| 缓存 | Redis 5.0 | 仅用于验证码与接口限流计数，登录态由 JWT 承载 |
| 对象存储 | MinIO | S3 兼容，支持 `composeObject` 零拷贝分片合并 |
| AI 集成 | Spring AI 1.0.0 | 通过 `spring-ai-starter-model-openai` 对接兼容端点、`spring-ai-starter-vector-store-pgvector` 读写向量库，统一对话与向量访问接口 |
| 大模型 | OpenAI 兼容协议（DashScope） | 统一对话与 Embedding 接口协议，通过配置切换服务商 |
| 文档解析 | EasyExcel + POI + PDFBox | EasyExcel 承载批量导入导出，POI 解析 docx、PDFBox 解析 pdf，供知识库摄入提取文本 |
| 接口文档 | SpringDoc OpenAPI 2.8.10 | 依据注解生成接口文档，经 `/swagger-ui.html` 在线调试 |
| 前端 | Vue 2.6 + Element UI 2.15 | 稳定基础库，实现动态路由与按钮级权限指令 |

## 系列规划

系列分为 27 期，按工程演进推进：

- **阶段一 · 起手（1–4 期）**：项目介绍 → docker 中间件编排 → 后端工程骨架 → 前端工程骨架
- **阶段二 · 地基（5–7 期）**：统一响应与枚举 → 三库 84 张表设计 → 双 Token 认证
- **阶段三 · 权限（8–10 期）**：前端无感续期 → RBAC 校验 → 动态路由
- **阶段四 · 基础模块（11–13 期）**：CRUD 规范 → 组织与权限维护 → 考勤打卡
- **阶段五 · 工作流与计算（14–17 期）**：请假表设计 → Flowable 落地 → 审批通过后的数据更新 → 加班与薪资核算
- **阶段六 · 文件与异步（18–20 期）**：MinIO 集成 → 分片上传与秒传 → 异步任务引擎
- **阶段七 · AI（21–24 期）**：知识库建模 → 摄入流水线 → 混合检索 → 智能问答
- **阶段八 · 收尾（25–27 期）**：典型故障复盘 → 架构设计复盘 → 部署上线

每期聚焦一个具体目标，结合关键代码片段与验证命令说明实现细节。
